# 노트북 실행 안내

`미션16_영화_역주행_분석.ipynb`는 기본 `submission_snapshot` 모드에서 API 키 없이 저장 자료를 다시 계산한다. 2026-10-11에 29개 셀을 위에서부터 실행해 오류 없이 끝났다. Python 3.12와 저장소의 requirements.txt에 있는 패키지를 사용했다.

1. 저장소 최상위에서 `pip install -r requirements.txt`를 실행한다.
2. Jupyter 또는 Google Colab에서 노트북을 열고 모두 실행한다.
3. 생성된 CSV·그림·ZIP 경로는 마지막 셀의 안내에서 확인한다.

새 수집은 Colab에서 `DATA_MODE`를 `live_fixed` 또는 `live_latest`로 바꾸고 기존 보안 비밀 `KOBIS_API_KEY`를 사용한다. 키 값을 코드에 붙여 넣거나 출력하지 않는다. 최신 모드의 공휴일 표·외부 사건은 해당 기간에 맞게 확인해야 한다. 최신 수집 전체 실행은 최종 검증 범위에 포함하지 않았다.

공개본은 전문가 20자평 원문을 제외했다. 별점·평가자 수·관객 분석은 제출본과 같다. 셀별 설명에서 분석 질문, 표본 선정 이유, 계산과 해석의 한계를 확인할 수 있다.
